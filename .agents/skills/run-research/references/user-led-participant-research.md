# Research carried out by the user

Codex does not depict an interview or test that did not take place. If you need contact with participants, prepare the `FIELDWORK-PACK.md` application next to `RESEARCH.md`.

Include the purpose of the decision, hypotheses, sampling criteria, recruiting, consent/privacy, script, assignments, non-leading questions, note template and synthesis rules. For each question, indicate why it is asked, what hypothesis it tests, and what decision it might change.

Prefer questions about the last actual case, actions, limitations and consequences. Don't ask "do you like the idea" as a substitute for behavior. After the user returns data, check sample quality and constraints before including findings in `RESEARCH.md`.
