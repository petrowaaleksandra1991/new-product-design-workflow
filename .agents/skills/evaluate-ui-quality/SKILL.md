# Rate UI quality

First, define the UX task, approved references and visual direction. Perform diagnostic passes in order: structure/grouping and hierarchy; scan path and rhythm; typography and interface copy; color roles/contrast; grid/alignment and density; affordance and UI details; accessibility; content/state stress. These are inspection lenses, not permission to automatically redraw each layer.

For the applicable screen block, use the questions from the “Exploratory screens” section [interface techniques](../../../product-design/sources/INTERFACE-CRAFT-METHOD.md). Check actual layouts and states; Do not turn numerical CSS recipes of the external set into a criterion for Figma.

Separate defect, preference and experiment. Link significant finding to UX-impact. If the improvement deviates from the direction, explain the effect and leave the choice to the user; Don’t average references into a safe, faceless version.
