# Build IA

Derive entities and tasks from approved evidence/PRD. Define relationships, ownership, lifecycle, navigation levels, labels, entry points, search/filtering and permissions. Check the fit between the user’s mental model and the product’s growth. Return the map, controversial places and questions; do not change the status of the stage.
