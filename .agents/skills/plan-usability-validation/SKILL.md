# Plan a review with participants

For each task, indicate the solution, hypothesis, behavior/signal, criterion, and risk. Formulate questions about past behavior and specific experiences, avoid pitching ideas and compliments. Give the user a script, consent/privacy notes, observation template, and synthesis plan. Don't create bogus answers.

When the user returns actual results, include `synthesize-usability-results` to analyze them; this plan in itself is not the result of the test.
