# Show project status

Read `PROJECT-STATUS.md`, the latest associated records `DECISION-LOG.md` and passports of only the current and next artifact. Don't re-read the entire project. If an approved result input has changed, point-to-point compare its version with the versions of the inputs in the affected downstream passports; Report discrepancies even when the status table has not yet been updated.

Return in ordinary language: the current stage; what is approved; what awaits decision; stale/blocked/skipped; important risks; missing inputs; one recommended next step and acceptable alternatives. Don't change files or run the stage.
