# Role contract

The role limits the analysis within the current stage. It is not a separate workflow and does not receive the right to start the next stage.

Each role gets the exact input, scope, output, and prohibitions. The decisions are left to the user.

## Independent review

The author of the result is not assigned to its independent reviewer. For the review stage, the main agent transmits to the individual performer in a fresh context: the exact version of the result being checked, versions of the necessary inputs, user decisions and criteria from the corresponding review skill. Do not pass on the author's self-assessments and rough arguments as the basis for a verdict. Use the corresponding role profile from this folder.

Reviewer can read the listed inputs and source screens, but does not modify the document being reviewed, the Figma layout, or other source results. Writing is allowed only to the review report after findings are returned to the main agent. The main agent shows the findings to the user without correcting the source on behalf of the reviewer.

If no individual author or fresh context is available, don't call the check independent: offer a self-check labeled `author-check`, or ask the user to set up a separate check. The presence of this file does not in itself guarantee isolation or technical prohibition of recording.
