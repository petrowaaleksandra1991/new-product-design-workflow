# Glossary

- **Artifact** — the main verifiable result of the stage; may include many methods and applications.
- **Checkpoint** — stop for the user’s decision.
- **Greenfield** - the product is created without a ready-made interface and a mandatory design system.
- **Evidence** is verifiable data or source, not opinion.
- **Hypothesis** is an explanation or solution that still requires verification.
- **Outcome** — change for the user, product or business; the screen itself is the output.
- **Pattern** is a repeatable model for solving a problem, not necessarily a visual template.
- **Timeline** — the user’s path in time with branches, interruptions and returns.
- **IA** - information architecture: organization of objects, sections and navigation.
- **Wireframe** - low-detail layout for testing logic and content.
- **Exploratory screen** - a detailed, but still changeable screen without standard status.
- **Foundation** - the basic rule of color, typography, grid, spacing, shape or motion.
- **Token** is a named value that associates the foundation with the interface.
- **Candidate** is a proposal for a future system, not permission to create a component.
- **Guardrail metric** is a protective metric that prevents the main target from being improved in a harmful way.
- **Storybook** - an interactive catalog of already implemented code components; not required in the greenfield set.
