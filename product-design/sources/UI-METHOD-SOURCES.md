# Methodological sources UI and UX

This registry specifies a review lens, not a predefined style. Skills use only the relevant part and do not reproduce books.

## UX and usability

- Nielsen Norman Group - heuristics, research, forms, navigation, errors and accessibility: https://www.nngroup.com/
- W3C WAI / WCAG 2.2 - Availability: https://www.w3.org/WAI/standards-guidelines/wcag/
- Rob Fitzpatrick, Ask Mom - asking non-leading questions about actual past behavior.

## Composition, grid and perception

- Timothy Samara, *Making and Breaking the Grid* - grid and conscious deviations.
- Ellen Lupton, *Thinking with Type* - typographic hierarchy and readability.
- Robert Bringhurst, *The Elements of Typographic Style* - typographic relationships.
- Rudolf Arnheim, *Art and Visual Perception* - visual balance and perception.
- Johannes Itten, *The Art of Color* - color relationships; not to be used as the sole basis for accessibility.
- Johannes Itten, *Design and Form* - form, contrast and composition exercises.
- Donis A. Dondis, *A Primer of Visual Literacy* - visual syntax.

## Rule of application

Priority: approved tasks and evidence → provided assets/references → accessibility/platform rules → theoretical diagnostics → taste preference. If sources conflict, show a compromise; theory does not cancel UX or turn subjective choice into fact.

## Methodological prototypes and third-party skills

- the local set `skills-efir-24-09/wireframe-board` is studied as an example of an HTML review board; Only the general idea was transferred to the workflow, and the platform, scope and structure were rethought in an original way;
- [Jakub Krehel / skills, revision `267330e`](https://github.com/jakubkrehel/skills/tree/267330e1adfc66a718fb65fa6918c1f06d0a689e), MIT, reviewed 2026-09-27 — one external reference considered during work on layout, typography, color, and UI polish. No upstream files, wording, scripts, commands, or executable recipes are copied into this workflow; external numeric and CSS recommendations do not become required Figma tokens;
- `deslop/sasha`, Ponytail, and other third-party resources are not incorporated into the workflow without checking the exact revision, license, hooks/scripts, and data access.

The third-party skill is a method/provider of evidence, not a product solution. The integration is fixed in `SKILL-CONTRACT.md` and must have a fallback.
